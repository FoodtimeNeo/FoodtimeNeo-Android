# 默认食物插图

原来的动态线稿按容器宽高分别绘制，扁宽框使图形变形，圆形半径又按宽度计算，可能越出高度范围。现在统一使用 120×100 的食物矢量画布和 FIT_CENTER，保留边距，避免压扁或裁掉笔画。

三幅图形使用现有手账配色、少量填色和清晰轮廓，分别为饭碗、餐盘、饺子。`Ui.foodDoodle` 保留旧调用接口，按 variant 复用这些资源；color 仅保留透明度语义，避免整幅图被单色覆盖。图片缺失页、今日推荐、列表与加载装饰统一使用。

首页主视觉去掉重复的三幅扁图，改为一句提示与等比例插图；文本高度随字号增长，不再固定两行高度。全局纸张风格、真实图片和原始上传文件不改变。

原生专项覆盖 9 个 variant × 3 种宽高，实际绘制、比例和边界共 81 项检查。
