# v1.5.0 构建说明

`versionName` 为 `1.5.0`，`versionCode` 为 `19`。验收包通过 Android CD 在 `dev` 生成，沿用 v1.4.3 正式签名。验收时核对包名、版本、校验和及覆盖升级。

- 信箱和关注／粉丝列表可按昵称搜索同学，从搜索结果关注或发私信。
- 社区帖子和全屏看图默认读缩略图，用户可单独加载当前原图。全屏支持单击关闭、双击缩放和双指缩放。
- 帖子详情使用固定互动栏和平铺评论。发评论与回复使用独立输入面板，楼内回复保留实际回复对象。

启用线上用户搜索前，需要部署包含 `GET /api/v1/users/search` 的后端版本。媒体读取沿用现有 `thumb` 与 `full` 接口。
