# v2.1.5 正式版更新说明

发布日期：2026-11-25。Android versionName 2.1.5、versionCode 31，沿用原包名与正式签名，可覆盖升级。

## 更新内容

- 全面升级 Web 与 Android 两端的“轻手账 / 现代编辑部”视觉语言：柔和圆角卡片与细腻层级投影、暖炭黑护眼深色模式及 WCAG 提亮朱红强调色。
- 优化双端导航壳层：Web 端移动端隐藏面包屑、底栏升级为线性图标与激活胶囊、顶栏去噪；Android 端底栏引入线性图标、精简顶栏返回与动态页标题。
- 升级食堂与搜索体验：Android 食堂首屏升级为外卖/点评式发现流（搜索胶囊 + 地图入口 + 今日推荐 + 分区筛选双列网格）；双端双栏菜单红条/吸顶头、金色星级与价格分层排版，单菜搜索结果改为横排卡片。
- 优化地图、社区、菜品详情、个人中心与鉴权表单：悬浮缩放控件与胶囊分区栏、无图社区便签摘录卡（保留社区手账标题）、个人中心卡片容器化、菜品详情评分徽章与点评圆角卡、登录/注册/找回密码与弹窗视觉统一。

## 部署与升级

相对 v2.1.4 无新增数据库迁移，V1–V60 不变。先更新 Backend，再由 Android main CD 构建正式签名 APK 与增量补丁，最后同步至 Web 下载目录并合并 Web main，由既有自动部署流程更新线上静态资源与公开 APP_RELEASE 参数。最低强制版本保持 0；保留登录、草稿、媒体、历史下载与旧 Web 哈希资源。

## 验证

Web、Android 与 Backend 各阶段发布 PR 及 main 准确提交均通过 GitHub Actions CI/CD 完整门禁校验；正式 APK 仅由通过 CI 的 Android main 经固定签名 CD 构建。

本轮未宣称完成 Redmi 全业务、真实 Safari/iOS 或生产定位验收；真实食堂坐标仍待采集，iOS 继续暂停。自动部署结果以本次 Actions 实际运行和线上公开接口核验为准。
