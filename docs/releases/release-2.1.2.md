# v2.1.2 正式版更新说明

发布日期：2026-11-24。Android versionName 2.1.2、versionCode 28，沿用原包名和固定正式签名，可覆盖安装，最低强制版本保持 0。

## 更新内容

- 修复帖子收藏的默认分组、自建收藏夹加载报错，统一分组筛选、总数、分页与账号隔离。
- 修复 Android 草稿首次进入时的页面加载错误，以及 Web 从“我的”进入草稿时弹窗立即消失的问题。
- Web、Android 发帖／草稿退出改为“保存草稿／不保存／继续编辑”。不保存只放弃本次修改，保留进入前的原稿及配图；保存失败继续保留编辑内容。
- Web、Android 新增“跟随系统／浅色／深色”，首次默认跟随系统，本机保存选择。统一正文、表单、弹窗、导航和图标的可读配色；红色图标与照片、校园地图原色保留。
- 修复 Android 个人页修改密码、提醒设置等图标，使用正确的线性图标。
- Android 新增品牌冷启动开屏，主界面在后方加载；从首次绘制至少显示 1.5 秒，就绪后进入主界面。同进程热启动不重复播放，失败可重试，整体等待 15 秒兜底。

## 部署和升级

相对 v2.1.1 无新增数据库迁移，V1–V60 保持不变。需要部署新版 Backend 才能修复收藏分组接口；先备份并升级 Backend，再部署 Web 和 Android 下载资源。沿用原数据库、邮件、Redis、媒体与鉴权配置，不清理登录、草稿或用户上传内容。

Web 部署使用随包工具合并旧哈希资源，保留旧版 assets 至少 7 天；HTML、版本信息与哈希文件分别设置缓存策略。更新参数仅合并 release-v2.1.2.env.example，不覆盖凭据；最低强制版本仍为 0。历史测试版和下载资源保留。

## 验证范围

功能集成基线：Web 693 项；Backend 434 单元／452 真实数据库集成；Android 222 单元、110 项界面和 24 项启动场景。版本准备及 main 均另跑准确提交的检查。Android 正式 APK 只由通过 main CI 的同一提交经 CD 使用固定正式签名构建，发布时核对包名、版本、签名、SHA-256 及补丁重建。

本轮只发布制品，不部署服务器。客户端自动化使用隔离 Android 35 模拟器和本地接口夹具，不替代 Redmi 全业务实机、真实 Safari/iOS 或生产验收。iOS 继续暂停。
