# v1.7.0 发布说明

`versionName` 为 `1.7.0`，`versionCode` 从 `19` 递增到 `20`。Android CD 从通过 CI 的 `main` 合并提交构建，沿用正式包名 `cn.edu.bjtu.foodtime` 和固定签名。

- 支持跨食堂搜菜、收藏菜品，以及发帖时在同一表单内按食堂、档口、菜品筛选和关联。
- 社区新增关注流、作者主页、内容举报和私信拉黑。社区四个分类可跟手横滑，下拉刷新期间保留已有列表。
- 完善私信未读提醒和帖子分享。打开分享链接可直达食记。

应用内升级和新增接口需配合 Backend v1.7.0 部署。正式 APK 和更新清单以本仓库的 GitHub Release 为准。
