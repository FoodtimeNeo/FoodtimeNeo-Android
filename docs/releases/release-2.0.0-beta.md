# v2.0.0β 测试版更新说明

发布日期：2026-11-20。展示版本保留 β；Web/Maven 内部版本为 `2.0.0-beta`，Android `versionName=2.0.0β`、`versionCode=24`。本版为可选测试更新，保留 v1.8.0 正式版下载，不强制升级。

## 相对 v2.0.0α 的更新

- 新增食堂地图：支持缩放、拖动、食堂轮廓与名称点选、同楼楼层目录入口；无关联区域显示名称，目录读取失败可重试。暂不提供定位或路线导航，教工、学苑及东区清真暂不标注。
- 精简个人及管理入口，菜品与帖子收藏分开；首页、搜索图标与社区对齐，手机管理菜单按需展开，可选学校邮箱认证与账号编号折叠。
- 重绘餐碗、餐盘等食物插画，修复默认图压扁、越界与首页顶部布局问题。
- Android 冷启动取消独立连接开屏，无会话直接进入登录；有会话展示中性骨架并由后端验证身份，失败可重试，受限会话规则保持不变。
- 补齐收藏默认分组与直接新建入口，修复分组保存及控件样式；修复 Android 帖子初次进入时图片宽度偏移。
- 反馈 CSV 自带“处理状态、处理建议”，后者作为给用户的回复；兼容旧“回复”列，两端导入提示与模板对齐。
- 菜品搜索保留页码、筛选及详情返回滚动位置，刷新不再让列表发生额外位移。

## 发布验证范围

功能集成已通过 Web 623 项测试与 144 项 Chromium/Windows WebKit 检查；Android 213 项单元及架构、Lint、构建通过，原生专项 110 项，另做 320dp/130% 字体导航 10 项。发布准备与准确 main 提交还要分别通过本次 CI；正式签名 APK 仅由通过 main CI 的同一提交经 CD 生成。

浏览器／模拟器交互检查使用受控本地接口，不等同于全业务实机、真实 Safari 或 Apple Simulator 验收。独立 iOS 应用、PWA 专项及校内道路导航均未在本版实现。

## 部署顺序

本轮只发布制品，线上部署由项目负责人执行。部署前备份数据库、上传文件与配置，先升级 Backend，再更新 Web 并开放新版 Android 下载。相对 v2.0.0α 无新增 Flyway 迁移，最新仍为 V57；从 v1.8.0 升级需依次应用 V47–V57，保留原迁移和数据。

如需启用可选测试版提示，按公开配置 `release-v2.0.0-beta.env.example` 设置 APP_RELEASE_*，最低强制版本保持 0；使用整数 versionCode 判断升级，不按 α/β 字符排序。保留现有生产凭据和其它配置，不用示例覆盖整份环境文件。
