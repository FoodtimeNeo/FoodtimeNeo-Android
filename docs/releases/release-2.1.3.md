# v2.1.3 正式版更新说明

发布日期：2026-11-24。Android versionName 2.1.3、versionCode 29，沿用原包名和固定正式签名，可覆盖安装，最低强制版本保持 0。

## 更新内容

- 合并首页与社区搜索，使用“菜品／笔记”统一入口；保留按账号隔离的最近10条本机搜索历史。
- 菜品结果按“档口（食堂）”分组，按档口分页；卡片随可用宽度排列，普通手机约四列，横滑继续读取匹配菜品。
- 收紧菜名、价格与评分间距，移除额外的“全部匹配菜品”行。菜品图片来自对应正式菜品。
- 排序与筛选独立。菜品支持食堂、价格、评分；笔记支持关联食堂、原创／转发、最新与点赞排序。修改待审核或删除的笔记同步移出搜索结果。
- 两端排序下箭头改为独立居中图标，“菜品／笔记”从左侧紧凑排列，适配浅色与深色外观。
- 接入一次前台定位及食堂直线距离排序，设备位置仅临时用于查询。真实食堂WGS84坐标尚待采集校准，默认不显示估算距离，无坐标时仍可正常搜索。

## 部署和升级

相对 v2.1.2 无新增数据库迁移，V1–V60 原字节不变。必须先部署 Backend，再更新 Web 与 Android 下载资源，新客户端统一搜索依赖新增后端接口。沿用原数据库、Redis、邮件、媒体及鉴权配置，不清理登录、草稿或上传内容。

真实坐标可在核实后通过独立的 app.search.halls 配置提供，键为食堂UUID，值包含WGS84纬度、经度和必填来源；详见 docs/modules/unified-search.md。手绘地图不换算米数，直线距离不表示步行路线；本版无需预填坐标即可部署。

Web 部署使用随包工具合并旧哈希资源，旧版 assets 至少保留7天；HTML、版本信息与哈希文件采用分别的缓存策略。更新参数仅合并 release-v2.1.3.env.example，不覆盖凭据；最低强制版本仍为0，历史测试版与下载资源保留。

## 验证与发布范围

功能集成基线：Web704项；Backend435单元／457真实数据库集成；Android224单元、126界面和24启动场景。版本准备与main另行核验准确提交。正式APK仅从main准确提交CI成功后，经CD使用固定签名构建，发布时核对包名、版本、签名、SHA-256及补丁重建。

本轮发布制品，不部署服务器。浏览器／模拟器和隔离接口不替代Redmi全业务、真实Safari/iOS、生产定位或生产部署验收；iOS继续暂停。
