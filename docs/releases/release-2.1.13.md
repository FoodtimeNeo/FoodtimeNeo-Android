# v2.1.13 更新说明

Android versionName 为 `2.1.13`，versionCode 为 `39`，沿用原包名和正式签名。

- 新增「精准选餐」独立页面，并在食堂页顶部提供快捷入口，支持按单份价格区间、品类、食材、做法、风格口味和忌口排除组合条件智能推荐，并支持“换一道”与无完全匹配时逐步放宽提示。
- 统一搜索页新增按份价区间、多维菜品标签（含单份过滤）与忌口排除筛选，结果卡片与菜品详情页同步展示结构化菜品标签。
- 对齐后端 `v2.1.13` 菜品标签字典与精准推荐接口（`GET /api/v1/dishes/tags`、`POST /api/v1/recommendations/dishes/query`）。

正式 APK 与更新清单由本次 Android main 的 CI/CD 生成。同步到 Web 下载目录时，以实际生成的签名制品、版本和校验结果为准。
