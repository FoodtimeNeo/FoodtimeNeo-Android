# v2.1.0 正式版更新说明

发布日期：2026-11-23。Android versionCode 26，版本名 2.1.0，沿用原包名和正式签名，可覆盖升级；不提高最低强制升级版本。

## 本版内容

- Web 增加版本检测和安全更新：空闲时自动刷新；编辑、上传、提交和草稿保存期间暂缓更新，保留登录和本机数据。部署时保留旧静态资源，减少旧页面与新资源混用造成的错误。
- Web 仅对适合重试的读取请求短暂重试，真实服务器错误附带请求编号；后端配套记录客户端构建编号与请求编号，便于定位问题。
- 精简重复说明文案，调整首页、个人页和帖子操作布局，保留手账风格及原有功能入口。
- 搜索增加账号隔离的本机最近 10 条关键词，支持单条删除及清空；退出登录保留、注销清理。
- 食堂采用左右联动菜单：左侧档口，右侧连续展示菜品；点选定位、滑动同步、返回恢复位置，保留档口详情入口。
- 修复 Android 个人页统计数字与刷新排版，避免多分组重复统计及分页数量截断；补齐 Web 菜品价格单位“元”。

## 发布与部署

三个仓库分别经发布 PR 使用 merge commit 合入 main，保留集成分支。Android 仅由准确 main CI 通过后的同一提交经 CD 构建正式签名 APK；Web、Backend 使用准确 main CI 制品。本轮只发布制品，不部署服务器。

从 v2.0.0 升级无新增数据库迁移，V1–V58 保持不变。先备份数据库、上传文件和配置，再升级 Backend，健康后部署 Web 和 Android 下载文件。公开更新参数见 release-v2.1.0.env.example，最低强制版本仍为 0。

Web 部署请遵循 docs/modules/safe-web-updates.md：使用发布目录准备工具验证入口和构建编号，保留旧哈希静态资源后切换目录；HTML、版本信息与哈希资源采用各自缓存策略。不可覆盖或删除用户上传文件、登录信息和草稿。已经打开且尚无新检测机制的旧页面无法被新代码立即接管，应保留兼容资源并允许自然更新。

## 验证边界

本次检查、准确提交和制品摘要以发布报告为准。自动化及独立 Android 模拟器不能替代 Redmi 全业务实机或实际 Safari/iOS 模拟器验收。iOS 开发继续暂停；路线导航、语音验证码未纳入本次发布。
