# v2.1.4 正式版更新说明

发布日期：2026-11-24。Android versionName 2.1.4、versionCode 30，沿用原包名与正式签名，可覆盖升级。

## 更新内容

- 搜索顶部控件统一背景；档口与菜品长名称单行省略，价格使用普通小数显示，修复10元显示为科学计数法的问题。
- 清空关键词返回历史与每日档口推荐；输入关键词时显示真实匹配建议，建议及搜索结果高亮匹配文字。
- 补齐普通公开菜品搜索的本地缓存：静默校验特征值，未变化时复用本地副本；带定位查询与私人内容不进入公共缓存。
- 帖子收藏先展示“全部”、默认及自建收藏夹，进入后查看内容；移除大条刷新按钮，保留手势刷新。
- 保留既有 Web 全局顶部栏与底部导航，本版未调整这两处布局。

## 部署与升级

相对 v2.1.3 无新增数据库迁移，V1–V60 不变。先更新 Backend，再更新 Web 与 Android 下载资源；最低强制版本保持0。保留登录、草稿、媒体、历史下载与旧 Web 哈希资源。

保留 main 上已有的自动部署流程：Backend 的 pom.xml 与 Web 的 package.json 版本变更触发构建和生产部署。Web 只有在正式 APK 核验并加入下载目录后才合入 main，随后由既有部署流程更新公开 APP_RELEASE 参数。
