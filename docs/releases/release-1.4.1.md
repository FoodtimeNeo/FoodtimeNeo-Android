# v1.4.1 发布说明

versionName 为 `1.4.1`，versionCode 为 `16`，沿用固定正式签名。`dev → main` 合并触发 CD 发布 `v1.4.1`。

## 修复

- **手机私信页适配**：改为固定顶栏（返回、联系人、刷新）与底部输入条，
  中间消息区独立滚动；输入条随键盘上移，首次进入和发送后滚到底部。
- **标签回退**：从社区进入私信后返回，再次点击「社区」直接回到社区首页，
  不再停留在私信或详情页。
- 私信页隐藏底部主导航，避免通用页面的标题、卡片与内边距影响聊天布局。

## 升级

- 覆盖 v1.4.0 的客户端可直接增量更新到 v1.4.1。
- 发布新 APK 后需同步更新 Web `public/downloads`（APK、SHA-256、manifest）与 `download.js`。
