# v1.4.0 发布说明

versionName 为 `1.4.0`，versionCode 为 `15`，沿用固定正式签名。`dev → main` 合并触发 CD 构建并发布 `v1.4.0`。

## 更新范围

- **社区互动消息**：信箱消息区分点赞/评论/回复，展示聚合人数；点击跳转原帖，按需加载楼层与回复并高亮定位。
- **一对一私信**：通知信箱新增「私信」标签与会话列表，新增聊天页（加载更早、刷新、发送、已读、隐藏）；社区作者栏提供快捷「私信」。
- **增量页面刷新**：食堂、档口、菜品、资料与信箱按区域刷新，保留静态内容和输入中的草稿；非目录页面静态壳优先显示。
- **安全加固**：退出/401 时清理私信会话、消息与未读缓存；更新下载只接受 http(s) 地址并校验 manifest 来源。

## 发布与联调

- 依赖 Backend v1.4.0（V39 互动消息、V40 私信）。
- 正式 APK 由 main 合并触发 CD；Web 下载制品需使用该 APK 并同步 `manifest.json`。
- 私信为纯文本，访客可读但发送由服务端拒绝。
