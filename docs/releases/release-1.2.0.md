# v1.2.0 发布说明

versionName 为 `1.2.0`，versionCode 为 `9`，包名仍为 `cn.edu.bjtu.foodtime`。沿用固定正式签名，`dev → main` 合并提交的 CI 成功后触发签名 APK 构建，Release 标签为 `v1.2.0`。

## 更新范围

- **应用内更新检查**：启动进入主界面时自动检查一次；「我的 → 检查更新」可手动触发。发现新版本时弹窗展示更新说明，`minVersionCode` 高于当前版本时不可跳过。
- **社区互动**：点赞爱心改为印章红、收藏星改为金色；点赞、收藏、评论点赞改为局部更新，不再整屏重建；提交评论后保留滚动位置。
- **图片加载**：重绘、切换页面、切后台返回均复用内存缓存，不再出现白屏重载。
- **评论区**：提交后立即显示「审核中」，审核通过后自动刷新为正式评论。
- **信箱**：公告列表直接渲染 Markdown。
- **关注**：新增「我的关注 / 关注我的」列表，社区食记支持关注作者。
- **菜品点评**：点赞按钮补回大拇指图标。
- **认证**：支持邮箱找回密码。
- 默认服务地址为 `https://bjtufoodtime.top/api/v1/`。

权限与接口见 [后端集成](../ops/backend-integration.md)。发布前运行架构检查、JVM 单元测试、Lint 和 Debug 构建，CI 另行验证。正式 APK 由本次 main 合并触发的 CD 构建并验证签名、版本和 SHA-256；Web 下载制品须使用此 APK，不能只更改旧包元数据。

GitHub 发布和 APK 构建不代表云服务器上的 Backend 已部署更新。
