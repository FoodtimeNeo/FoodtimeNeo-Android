# v2.0.0α 测试版发布说明

展示版本 `v2.0.0α`；npm／Maven 内部版本 `2.0.0-alpha`；Android `versionName=2.0.0α`、`versionCode=23`。这是测试版，正式用户可选择升级或稍后更新，不强制升级；GitHub 标为 prerelease，不替换 latest 正式发布。

- 社区新增发现页紧凑置顶区，超管最多置顶 3 条并排序；作者可修改本人未删除帖子的标题、正文、图片和关联菜品，重新审核后公开，保留原时间及互动，显示修改时间。
- 增加按账号隔离的本机单份发帖草稿、邀请注册完整流程、连续双击缩放及相册优先选择，精简冗余图片箭头、改善按钮间距和图片预览操作。
- 搜菜支持无关键词浏览、食堂多选、价格／评分与排序，缺失数据保留后排；数字分页含首尾、省略号及直接跳页。菜品图片可完整预览。
- 目录纠错、举报公开回执、追问、双方申诉、受限申诉会话补齐；保留审核及回复历史，实际处罚／恢复与结论分开。
- 菜品和帖子分别提供收藏分组与各 50 条浏览历史；Android 七类系统提醒完善调度、隐私与迁移，不承诺即时送达。
- 登录算术图片验证码从同设备滚动 15 分钟第二次登录请求触发；不增加旧客户端豁免。语音读题仍为后续扩展。
- 菜品增加价格变化入口、计价单位与阶梯走势；历史更正／删除默认仅超管，审计保留，当前价与最新历史保持一致。
- 非学校邮箱普通账号默认享有相同参与权限，学校邮箱绑定／解绑保留；可用服务器单一策略恢复校邮要求，不改变管理员边界。

## 发布与部署

本轮只合 main 并发布制品，不部署线上服务。部署应先备份并升级 Backend，再更新 Web／Android；从 v1.8.0 依次应用新增 V47–V57，不改旧迁移，不删除既有内容或审计。登录挑战不支持的旧客户端在达到条件后可能无法登录，应升级客户端。

应用内可选测试版提示由既有 `APP_RELEASE_*` 配置决定，配套公开配置见 `release-v2.0.0-alpha.env.example`；本轮不直接修改生产配置。Web 保留正式版下载，并另列测试版。Android 保持原包名和固定正式签名，更新按整数 versionCode 判断，不能按 α／β 字符排序。

自动化及模拟器结果不能替代用户实机验收；具体结果、尚未覆盖设备与制品来源以本次发布核验报告为准。
