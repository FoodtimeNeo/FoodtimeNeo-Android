# v2.1.1 正式版更新说明

发布日期：2026-11-23。Android versionCode 27，版本名 2.1.1，沿用原包名与固定正式签名，支持覆盖升级；最低强制版本仍为 0。

## 本版更新

- 修复 Android 首页点食堂仍进入旧档口卡片的问题，恢复左侧档口、右侧连续菜品的联动菜单；支持点选定位、滑动同步和详情返回位置恢复。
- Android 个人页按当前 Web 样式排列“常用、我的记录、服务”宫格，保留账号头部、权限与正确统计。
- 完善两端搜索前页面：最近 10 条本机账号隔离历史、发现词条和每日档口推荐图片卡片，点击推荐直达真实档口。修复 Android 输入框文字裁切；显式空搜索仍可浏览全部菜品。
- 集成组员的点评图片关联与审核，补齐点评到社区发帖的衔接及 Web 提交失败处理。
- 食堂、档口、菜品等公开目录与对应图片按访问静默缓存，每次先校验特征值，未变化复用副本、变化替换当前资源；任何网络可用。不放入安装包、不启动全量下载。Web 公共 JSON 和同站目录图片共用 100 MiB 上限；社区保持原缓存策略。账号、邮箱、私信、反馈及举报等私密数据不纳入此公共缓存。
- 新增独立 Android 35 模拟器 CI，实际覆盖首页入口、个人页、搜索、菜单联动和手势；测试夹具图片只用于自动化，不作为正式菜品默认图。

## 部署顺序与迁移

相对 v2.1.0 新增 V59__review_photo_link.sql、V60__public_catalog_revision.sql。V1–V58 不改写。先备份数据库、上传文件与配置，升级 Backend 并确认 Flyway 和健康检查成功，再部署 Web 与 Android 下载文件。已有数据库迁移不可通过降版本 JAR 自动回滚；回退应使用备份并核对新增数据，不删除或重写迁移。

更新提示使用 release-v2.1.1.env.example 中的公开参数，合并进现有配置，不覆盖凭据。Web 部署按随包的发布准备工具合并旧哈希资源，HTML、版本信息与哈希资源分别设置缓存策略。已有登录、草稿和用户上传文件保留；旧 α／β 下载资源保留，但不作为新于正式版的推荐。

## 制品与验证边界

三仓从集成分支通过发布 PR 以 merge commit 合入 main；Android 正式 APK 仅由准确 main CI 成功后的同一提交经 CD 使用固定正式签名构建。版本、签名、摘要、补丁重建和准确来源见最终制品清单。

自动化基线为 Web 682 项、Android 217 项、Backend 434 单元与 448 集成，以及 Android 35 模拟器 47 项；版本准备和 main 检查另记录准确运行结果。模拟器与本地浏览器夹具不能替代 Redmi 全业务实机、真实 Safari/iOS 或生产验收。iOS 继续暂停，路线导航和语音验证码未纳入本次发布。本轮只发布制品，不部署服务器。
