# v1.3.0 发布说明

versionName 为 `1.3.0`，versionCode 为 `10`，包名仍为 `cn.edu.bjtu.foodtime`。沿用固定正式签名，`dev → main` 合并提交的 CI 成功后触发签名 APK 构建，Release 标签为 `v1.3.0`。

## 更新范围

- **访客账号与学校邮箱绑定**：任意主流邮箱均可注册；非学校邮箱为只读访客，在「我的 → 绑定学校邮箱」完成验证后解锁发帖、评论、点赞与投稿。学校邮箱注册直接为普通用户。
- **注册邮箱白名单**：注册页与服务端一致，只接受 QQ、163、126、Gmail、Outlook、iCloud、学校邮箱等主流域名，允许 `vip.qq.com` 这类子域。
- **应用内更新**：开屏自动检查更新，「我的 → 检查更新」可手动触发；更新弹窗先于公告显示。优先下载 bsdiff 增量补丁（通常 1–3MB），缺失或校验失败自动回退完整 APK，支持断点续传、进度展示、SHA-256 校验和直接调起安装器。
- **图片上传 50MB**：客户端上限放宽到 50MB 并改为流式上传，避免大图占用内存；服务端会自动压缩到 5MB 左右。
- **关注/粉丝列表**：修复列表加载与布局，支持清晰的头像、昵称与回关操作。
- **管理看板**：接入真实统计接口，不再使用 mock 数据。
- **其他**：点评点赞图标、公告 Markdown、信箱刷新等交互修复。

权限与接口见 [后端集成](../ops/backend-integration.md)。发布前运行架构检查、JVM 单元测试、Lint 和 Debug 构建，CI 另行验证。正式 APK 由本次 main 合并触发的 CD 构建并验证签名、版本和 SHA-256；Web 下载制品须使用此 APK，不能只更改旧包元数据。

GitHub 发布和 APK 构建不代表云服务器上的 Backend 已部署更新；本轮新增的注册域名白名单、50MB 上传与增量更新配置见 Backend `docs/releases/release-1.3.0.md`。
