# v2.0.0 正式版更新说明

发布日期：2026-11-22。三端展示和内部版本均为 2.0.0，不带 α/β 后缀；Android versionCode 25，沿用原包名和固定正式签名，可从 v1.8.0、2.0.0α、2.0.0β 覆盖升级。应用更新仍可选择稍后，不新增强制升级要求。

## 本版内容

- 每日推荐由菜品调整为有图片的档口，展示食堂、评分与评价数，点击直接查看档口；评分按评分桶聚合，已有旧推荐快照自动重建。
- Android 首页增加一键点评，可按食堂逐级选菜或搜索菜品，复用原有评分、文字和可选图片提交流程。
- 修复 Web 找回密码页的装饰层拦截点击问题，恢复验证码发送、验证及返回操作。
- 整合 α/β 已有更新：食堂地图缩放拖动与食堂/楼层点选；首页、搜索、个人与管理入口整理；默认插画、图片比例及 Android 冷启动优化。
- 社区帖子修改与重新审核、紧凑置顶及排序；本机账号草稿、图片平滑切换/缩放、相册优先选择和图片初次偏移修复。
- 完善菜品搜索筛选、直接页码跳转和返回位置恢复；菜品/帖子分别收藏分组、默认分组、新建分组与浏览历史。
- 菜品价格历史与计价单位；目录纠错、举报/追问/双方申诉及受限申诉入口；反馈 CSV 自带处理状态/处理建议并兼容旧回复列。
- 既有注册邀请模式、登录图片验证码、账号注销/学校邮箱绑定与解绑、权限策略、通知隐私与调度等能力保留。

## 发布与部署

先验证准确集成提交及发布 PR，使用 merge commit 合入 main。Android 正式签名 APK 仅由通过 main CI 的同一提交经 CD 构建；Web 和 Backend 交付准确 main CI 制品。本轮不部署服务器。

部署前备份数据库、上传文件与配置。先升级 Backend，Flyway 从 β 新增 V58（每日档口推荐表），V1–V57 保持原字节不变；从 v1.8.0 升级则顺序应用 V47–V58。推荐响应已改为档口结构，后端与新版客户端需配套更新。

后端健康后部署 Web，再开放 Android 下载。公开更新参数见 release-v2.0.0.env.example；APP_RELEASE_MIN_VERSION_CODE 保持 0。站内下载/清单使用 HTTPS，版本、完整 APK、补丁、校验值必须配套。正式版替换 stable/latest，α/β 作为历史测试发布保留，不把旧 β 当作更高版本推荐。

## 验证边界

准确提交的自动测试、构建与制品核验结果见本次发布报告，不能把旧版本的测试数量当成本次结果。尚无本版全业务 Redmi 实机或实际 Safari/Apple Simulator 验收。iOS 暂停；语音验证码、GPS 定位与校园路线导航未在本版实现。Android 后台提醒受系统调度影响，不承诺即时。
