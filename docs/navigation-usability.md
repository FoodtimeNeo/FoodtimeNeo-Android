# 导航与个人入口

个人页按“收藏与回访、我的记录、消息与处理、账号与隐私”提供直接入口，菜品和帖子收藏保持独立。两端食堂页改用与社区一致的搜索图标，首页入口使用同类房子图标。沿用现有业务路由和权限，不把页面分组做成服务端业务分类。

Web 社区支持 tab 参数直接打开收藏或我的食记，并使切换与 URL 同步；创建动作消费一次，避免返回重复弹出。可选学校邮箱表单和账户编号折叠展示，减少占用首屏。移动端管理菜单展开后选择任务即收起，桌面保留常显目录。

Android 移除原个人页分栏选择器，常用入口不再藏在其他页签；编辑资料和检查更新保持触控高度与间距。管理区按内容目录、运营处理分组，原权限不变。
