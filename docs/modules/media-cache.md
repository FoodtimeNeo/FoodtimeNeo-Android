# 原生图片缓存

统一的View加载器仅装载当前可见图片，合并同身份、同地址和解码尺寸的请求，最多两个图片任务；离屏或销毁后取消无用任务。缩略图、原图独立缓存，解码按照目标像素采样。

社区帖子详情和全屏看图默认读取现有480px缩略图。“加载原图”仅升级当前图片，加载失败时保留缩略图并提供重试。翻图恢复缩略图，关闭时释放绑定；全屏画布支持单击关闭、双击缩放及复位、双指缩放、放大后拖动及原比例滑动翻图。按钮与可收起的帖子信息层独立于画布。菜品看图仍从其既有原图入口打开。

原生回归可用 `CommunityPhotoRunner`，调试后缀为 `.photocheck`，仅接受 `http://127.0.0.1:18081/api/v1/` 和本地样例帖 `postId`，通过 ADB reverse 连接。它检查图片实际解码尺寸、信息层折叠、双击与双指、原图按钮和关闭后的帖子路由。

Bitmap LRU按堆的1/8分配，最多32MiB；私有`cacheDir/media-v2`磁盘LRU最多200MiB，30天未使用可回收。缓存使用原子文件提交及正文校验，损坏或被系统回收时重新请求。公开新鲜图片可直接复用；私有图片每次展示先用ETag校验，通过304后复用字节；no-store预览不进入LRU。

私有缓存键包含来源、账号、角色及会话摘要。退出、改密、切号使旧任务失效，后台暂停时释放图片展示引用，前台恢复重新校验。HTTP只同步Cookie访问，不持有覆盖整个网络请求的锁；取消和会话变化后的响应不能恢复旧Cookie。

“我的→账号→清理图片缓存”仅清理图片，不删除会话、草稿或信箱状态。
