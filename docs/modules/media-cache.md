# 原生图片缓存

帖子内图片也移除两侧常驻箭头，保留指示点；点按指示点可选择图片，读屏滚动动作按页切换。图片解码导致的高度变化不重置当前横向位置，只有宽度变化才重新计算分页。

全屏触屏看图不再常驻左右箭头，左右滑动保持跟手及松手停靠；右上角“看图选项”按当前页提供上一张／下一张和缩放操作。画布支持读屏滚动动作及聚焦时的键盘左右键，首尾不越界；页码作为可访问描述同步更新。`CommunityPhotoRunner` 额外支持 `.interactionreview`＋`http://127.0.0.1:18094/api/v1/` 的独立验收组合，检查去除常驻箭头、读屏翻页边界和双击的中间缩放帧，不允许正式包或线上地址运行此测试。

统一的View加载器合并同身份、同地址和解码尺寸的请求，最多两个图片任务；离屏或销毁后取消无用任务。未命中缓存的普通列表图片仍按可见区域装载，全屏看图可准备相邻缩略图。已命中当前身份、新鲜的 Bitmap 缓存时，在 View attach 阶段同步恢复，不等待测量、可见性检查或异步消息。缩略图的 480px 解码键在测量前即可确定；缓存边界、身份隔离、过期和 `no-store` 规则保持不变。

社区横向切换只改变 `translationX`，不会自动触发图片加载器原先依赖的 scroll/layout 回调。分页器现在随位移重新检查新露出的区域；已完成绑定立即返回。仅剩磁盘缓存时，图片仍在后台解码，但可以在拖动过程中开始并完成，不再等松手停靠。新鲜内存缓存覆盖的左右两列在入屏前已经恢复。

社区帖子详情和全屏看图默认读取现有480px缩略图。“加载原图”仅升级当前图片，加载失败时保留缩略图并提供重试。翻图恢复缩略图，关闭时释放绑定；全屏画布支持单击关闭、双击缩放及复位、双指缩放、放大后拖动及原比例滑动翻图。双击缩放使用独立的 260ms 锚点缓出动画：以双击点为锚逐帧重算平移，新的双击从当前可见状态接续，拖动/双指/翻页/关闭会取消动画；系统关闭动画时立即生效。按钮与可收起的帖子信息层独立于画布。菜品看图仍从其既有原图入口打开。

原生回归可用 `CommunityPhotoRunner`，调试后缀为 `.photocheck`，仅接受 `http://127.0.0.1:18081/api/v1/` 和本地样例帖 `postId`，通过 ADB reverse 连接。它检查图片实际解码尺寸、信息层折叠、双击与双指、原图按钮和关闭后的帖子路由。

Bitmap LRU按堆的1/8分配，最多32MiB；私有`cacheDir/media-v2`磁盘LRU最多200MiB，30天未使用可回收。缓存使用原子文件提交及正文校验，损坏或被系统回收时重新请求。公开新鲜图片可直接复用；私有图片每次展示先用ETag校验，通过304后复用字节；no-store预览不进入LRU。

私有缓存键包含来源、账号、角色及会话摘要。退出、改密、切号使旧任务失效，后台暂停时释放图片展示引用，前台恢复重新校验。HTTP只同步Cookie访问，不持有覆盖整个网络请求的锁；取消和会话变化后的响应不能恢复旧Cookie。

“我的→账号→清理图片缓存”仅清理图片，不删除会话、草稿或信箱状态。

`CommunityCoverCacheRunner` 为上述时序问题提供原生回归，仅允许 `.covercachecheck` 独立调试包和 `http://127.0.0.1:18085/api/v1/` 本机夹具。`-e stress true` 覆盖 40 次左右切换、逐阶段双列 drawable、10 次深滚动退出重进首帧、详情返回、前后台、仅磁盘缓存、重复解码与绑定泄漏、过期、`no-store`、403、账号切换和门控迟到响应。测试须使用独立夹具；不连接生产服务，不代表用户实机验收。

## 相册优先图片选择（2026-11-12）

图片入口统一通过 `ImagePicker`：设备实际可解析系统 Photo Picker 时优先打开系统相册选择器，失败或不可用时回退 `ACTION_OPEN_DOCUMENT` 文件选择；不申请整库存储权限。头像单选、发帖按剩余名额多选，投稿/管理/证据入口复用同一适配器。选择结果可能在 `data` 或 `ClipData` 中返回，统一由 `ImagePicker.firstUri` 读取；选中后立即由 `PhotoImport` 复制到应用私有目录，不依赖临时 URI 长期可读。取消不删除已有草稿图片；超额、重复 URI、不可读/云端离线文件由现有导入流程拒绝并提示。演示/测试仍可通过 `MainActivity.imagePickerIntent()` 获得文件选择 Intent。
