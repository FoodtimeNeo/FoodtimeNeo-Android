# 本人申诉编辑

正常登录在「举报与处理决定 → 收到的决定 → 提交申诉」进入独立 `appeal-compose` 编辑页。它按决定编号读取服务器的本人投影和期限，复用受限页的 `AppealForm`，不复用普通应用导航权限。

`AppealRepository` 独立于目录和管理员处理接口；读取决定、动作和提交均核对请求前后的账号、会话模式与会话标识，受限账号不会被正常管理接口的 active 门槛误拦截。最终所有权、一次申诉和七天期限仍由服务器执行。

表单支持最多三张证据和预览、移除、更换。文字、重试编号与证据按 API 来源／账号／决定隔离；选择器返回后继续编辑。每次上传成功立即保留引用，后续上传或申诉关联失败不会重新上传已完成的图片；关联重试复用请求编号。成功清理本人草稿。未提交时返回或重新进入保留内容，其他账号看不到同一决定下的材料。

提交前按 Unicode 码点检查 2000 字，上传和提交期间锁定编辑，失败留在编辑页恢复操作。受限页的图片移除／重绘仍留在受限界面，不能出现普通应用导航。

对应检查包括真实 HTTP 的本人读取／证据字段／受限会话／迟到响应隔离，以及隔离模拟器的实际入口、系统触摸、相册生命周期、PhotoImport、部分上传失败和关联重试。模拟器图片返回使用受控 URI，不能描述为完整人工系统相册选图验收。全面实机与跨设备验收另行进行。
