# 冷启动开屏

仅进程首次打开时显示品牌封面。`ColdStartSplash` 将封面放在正常页面上方，页面照常测量、恢复会话及加载数据，不阻塞主线程，也不延后主界面请求。

- 最短显示 1500ms，从品牌封面第一次绘制起计算。内容准备完成且达到最短时间后移除。
- 计时状态只保存在进程内。返回后台再打开、同进程重新创建 Activity 不重播；配置重建不重新开始计时。启动中主动退出后，同进程再次打开也不重播。
- 网络失败优先展示现有可重试错误页；总启动等待达到 15 秒仍未完成时，显示启动超时与重试，旧页面回调不能覆盖该状态。
- 更新、公告弹窗在开屏移除后展示；停用账号仍进入原受限申诉页，未登录仍进入原登录页，不改变鉴权或业务入口。
- 配色沿用 `AppTheme` 和 `Design`，随当前浅色／深色设置变化。照片、地图不反色。

`StartupGate` 是不依赖 Android 的计时规则；页面只报告内容就绪。修改品牌排版、最短时长、超时策略时分别调整对应层，避免把计时分散在网络或页面代码中。

验证：`StartupGateTest` 覆盖快速、慢速、首次绘制、重建与超时边界。隔离模拟器检查通过 `scripts/verify-compact-layout.sh` 执行，包含快速启动、慢加载、会话失败、累计超时、同进程再次启动与启动中途退出；只允许 `.layoutreview` 包和本地夹具地址，不使用生产账号。
