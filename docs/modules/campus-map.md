# 食堂地图

原生 `CampusMapScreen` 使用 bundled WebP 底图及独立 JSON 区域，不使用 WebView、地图 SDK 或 GPS。入口为食堂首页的“食堂地图”，点选名称／轮廓后显示对应有效目录入口；同楼多层分项展示。无关联和读取失败有明确提示和重试。

底图为用户提供的北京交通大学招生办公室手绘地图（2023 年 6 月更新），图像坐标 5032×3579。读取位图在后台执行，按二分之一采样控制内存；绘制和命中统一使用原图坐标与同一缩放平移，离开页面释放位图。该数据不是经纬度，不能用来测距。

当前六个可选择区域及暂不标注项与 Web 对齐。区域 ID 与食堂 ID 分离，没有目录关联的益民只显示名称；不新增假食堂。楼层使用现有目录名称。

手势支持双指缩放与拖动，拖动不误触点选；另有缩放、全图和食堂名称按钮作为等效操作。地图读取失败仍保留名称选择。保留页面选区与视图位置，返回后可继续查看。

当前不提供路线导航。后续采用独立道路网与入口连接点维护，不从图片轮廓推断道路可通行。
