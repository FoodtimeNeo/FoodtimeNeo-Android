# 餐厅与档口加载

首次进入档口、菜品列表立即显示目标名称、返回和底部导航；读取超过180ms才显示匹配双列卡片的骨架，避免快速请求闪烁。常规等待不增加说明文案；3秒显示慢网提示，15秒终止本轮读取并提供重试。内容就绪即能操作，图片独立加载。

同一账号和目标页的刷新保留卡片、草稿与滚动位置，只增加“更新中”。网络失败可保留当前目录内容并提示重试；权限失败隐藏旧内容。快速返回、目标切换、后台和销毁会取消旧任务，迟到结果不能恢复旧页面。骨架和150ms淡入遵守系统动画开关。

公告轮询使用独立后台执行器，最多一个在途任务。新公告在前台且页面内容就绪后排队展示；加载、失败重试、写操作和其他弹窗期间不打断。退出、切号及生命周期变化后的旧公告回调失效；轮询不重新构建目录列表。

此范围不包含启动开屏改版。
