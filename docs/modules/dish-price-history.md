# 菜品价格变化

`PriceHistoryRepository` 独立处理价格快照和历史管理，`PriceHistory` 不可变模型处理单位区间、未知值与连续同价压缩，`PriceHistoryChart` 只负责 Canvas 和输入。

详情进入 `price-history`，支持全部／近30／90天、点击及真实键盘选择、逐批展开明细。服务器提供时间范围，客户端按北京时间展示；保留完整记录时间，不将未知当零。

`canManage` 来自服务器的独立能力投影；金额和单位在普通管理和纠错可维护。更正／删除使用目录版本防冲突，错误保留输入与刷新入口；最新值同步当前价，唯一记录不提供删除操作，服务器仍校验。

历史页读到的新状态会要求下次菜品详情等待新数据，避免返回时闪现旧价。更正对话框使用可滚动内容，随所属页面移除而关闭；后台写入前核对原账号，仓库在请求前后核对会话。

配套后端 V55，发布需先升级后端。本模块不决定版本发布或自动升级渠道。
