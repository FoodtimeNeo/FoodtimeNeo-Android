# 本机发帖草稿（2026-11-12）

每账号在当前设备只保留一份活动发帖草稿，按账号 UUID 隔离；不建设云同步、多份草稿箱或跨设备同步。

## 存储与恢复

- `PostDraftStore` 将标题、正文、关联菜品 ID、图片文件路径、更新时间和 revision 写入应用私有目录 `filesDir/post-drafts/<accountUuid>/draft.json`；写入使用临时文件后重命名。
- 图片由现有 `PhotoImport` 复制到应用私有目录，草稿只保存可长期读取的本地路径；不保存临时 `content://` URI。
- 编辑标题、正文后约 500ms 防抖保存；增删/排序图片、关联菜品变化立即保存。空白标题、正文和图片不生成草稿。
- 冷启动或进程重建后进入发帖页，在 Activity Bundle 为空时从本机草稿恢复；缺失图片仍可移除或重选，文字不受影响。
- 页面提示“关闭或返回后自动保存”；只有服务器确认发帖成功后才删除草稿。普通退出登录保留草稿，原账号重新登录可恢复；注销成功时清理该 UUID 的草稿目录。
- 每个账号最多一份活动草稿；没有跨账号总份数额度，受本机空间限制。保存失败保留当前编辑内容和上一个有效版本，不显示“已保存”。

## 边界

- 发帖仍由服务器审核和权限校验；本机草稿不代表已发布，也不绕过 visitor 的发布限制。
- 关联菜品仅在当前草稿中保存 ID，发布前仍以服务器目录可见性为准。
- 同一账号在多台设备上各自保存本机草稿，不声称一致或同步。
