# 登录公告展示

需要先升级 Backend V45；管理入口和排期规则见 [公告管理与排期](notice-management.md)。客户端在主动登录、冷启动或页面刷新恢复会话、返回前台时请求 GET /users/me/notices/current-set，不定时轮询。普通导航不重查；退出和切号清除状态并丢弃旧回调。Android 旋转保留本次会话状态。

响应为数组，最多两条，更新公告优先，再普通公告。发布时间与是否仍有效由服务器统一判断；时间均按固定 UTC+8 展示。关闭或确认第一条后重新向服务器校验第二条，避免阅读期间过期。同一会话同一公告只显示一次，下次恢复会话可再次显示尚未免弹的公告。

打开不写已读。点击确认才 POST /users/me/notices/{id}/confirm，发送 dontShowAgain 布尔值；复选框默认关闭。勾选免弹后在服务端跨设备保存，不回退弹出同类旧公告。失败保留弹窗和选择并可重试。确认始终使用实际显示的公告 ID。到期或停用仅停止弹窗，信箱仍保留已发布公告；草稿及未来发布时间的公告不会进入信箱。

Markdown 继续使用经过清洗的 Web 渲染和 Android 原生 spans，支持标题、强调、列表、表格、链接和网络图片；不执行原始脚本或本地文件图片。历史详情使用相同渲染和确认行为。检查失败不阻止主功能，可在信箱重试。

## 社区互动消息

系统消息页识别 `LIKE_POST`、`LIKE_COMMENT`、`COMMENT_POST`、`REPLY_COMMENT`，显示分类图标、聚合人数与「查看原帖」。点击会先标记已读，再携带 `refCommentId`/`refRootCommentId` 进入社区帖子详情；详情在后台按需加载楼层与回复分页，找到目标评论后滚动并短暂高亮，找不到时保留普通列表。互动消息的生成与聚合规则见 Backend `docs/modules/notices.md`。

## 私信

通知信箱新增「私信」标签：展示会话列表、最后一条消息与未读角标；点击进入聊天页，消息按时间正序、自己靠右显示，支持加载更早消息、刷新、发送（1000 字上限）和隐藏会话。社区食记作者栏提供「私信」入口；访客可查看与已读，但发送会被服务端拒绝。
