# 作者修改食记

`PostEditScreen` 使用独立 `PostEditRepository.Edit` 契约，当前正常会话中本人未删除帖子可打开；非本人或受限申诉会话没有入口。标题、正文、照片和关联菜品可修改，转发来源保持不变；详情展示 `editedAt`，模型更新点赞／收藏时保留内容版本和修改时间。

编辑页以 `community-edit:{postId}` 路由隔离临时输入与所见版本，共用相册、照片排序与菜品选择。`CommunityScreen.persistDraft` 只处理新发帖路由，编辑既有帖子不能覆盖／删除本机唯一发帖草稿。返回放弃须确认；提交成功重新读取同一帖子并使社区缓存失效，恢复中的后台操作沿用相同清理规则。

完整替换带 `expectedRevision` 与 `clientRequestId`；同一载荷失败重试沿用编号、已上传文件复用引用。上传前后及关联前核对账号，跨账号旧上传不得继续关联。版本冲突保留输入，提供明确提示及“读取最新帖子”确认，不能自动升级版本后覆盖。

作者提交后整帖回到审核，原计数、评论、收藏与时间保留；转发允许不配图，原创仍须至少一张。人工审核通过／拒绝携带实际完整详情版本，评论保持独立审核契约。置顶管理继续走独立能力，修改只依赖其状态联动。

JVM 真实回环 HTTP 检查版本传递、模型保留、上传复用和切号；隔离调试包在模拟器验证实际详情入口、系统触摸、失败重试、版本冲突、返回和发帖草稿隔离。模拟器不能替代用户手机验收。后端 V57 先于客户端升级，不涉及正式 APK 或线上部署。
