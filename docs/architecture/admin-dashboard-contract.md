# 平台数据看板接口约定

前端路由为 `admin-dashboard`，仅向有效 `superadmin` 开放。已接入后端真实统计，由 `ContentRequest.Query.ADMIN_DASHBOARD` 请求数据，再通过 `FoodtimeRepository.adminDashboard()` 向界面提供不可变快照；没有成功快照时返回 null，不提供样例数据。

当前接口：`GET /api/v1/admin/dashboard?days=30`，标准 `ApiResponse` 包装。一次读取完整 30 日快照，默认展示末 7 日，可切换全部 30 日；以下为 `.data` 字段结构示例（数值仅用于说明，趋势实际返回 30 项）。

响应结构：

```json
{
  "totalUsers": 1286,
  "registeredUsers": 1248,
  "onlineUsers": 86,
  "reviews": 3862,
  "replies": 5917,
  "posts": 742,
  "halls": 7,
  "stalls": 46,
  "dishes": 618,
  "generatedAt": "2026-10-30T12:00:00Z",
  "trend": [
    {
      "day": "2026-10-24",
      "totalUsers": 1230,
      "newUsers": 7,
      "newReviews": 68,
      "newReplies": 104,
      "newPosts": 12,
      "onlinePeak": 91
    }
  ]
}
```

约定：

- 所有累计值和增量值均为非负整数。
- `totalUsers` 为全部注册账号，含停用账号；`trend[].totalUsers` 为截至相应业务日的累计注册数。停用账号不抹去历史累计。
- `registeredUsers` 仅计有效账号；点评、回复、食记累计值计正式内容，食堂、档口、菜品计启用项。
- `onlineUsers` 为最近 5 分钟产生已认证请求的去重用户数，同账号多端计一次。
- `day` 为 Asia/Shanghai 的业务日期，客户端保存为 LocalDate；设备时区不改变横轴日期。返回连续日期，无数据日由后端补零。
- `trend` 返回含当日的最近 30 个自然日，接口支持 days=1..31，Android 固定请求 30 日。趋势周期选择仅截取同一快照末 7 或 30 日，不额外取数；累计指标和当前在线不随周期变化。
- 新增汇总同时显示今日、近 7 日和近 30 日注册、点评投稿、回复和食记创建数。纯 Java 模型按服务端业务日期取末 1/7/30 项聚合，不拼接不同请求的统计。
- 趋势中的 `newReviews` 为点评投稿（含待审等状态），`newReplies` 为新回复，`newPosts` 为新建食记记录；与累计正式内容的统计范围不同。
- `onlinePeak` 历史字段名保留，实际为当日行为去重人数，界面显示“日活用户”，不是并发峰值。
- 权限不足返回 `403`，普通管理员不可读取平台级数据。
- `generatedAt` 用于判断缓存新鲜度，前端不根据客户端时间推导统计结果。
- `generatedAt` 按北京时间显示，并标注时区。进入页面、返回前台及手动刷新会重新读取；趋势切换只使用当前快照，不轮询。
- 首次失败显示错误和重试；后续网络/服务故障保留上次快照并明确提示。401、403、退出、换号、角色或账号状态变化清除受保护快照；旧请求不能覆盖新账号或较新请求。
- 缺失字段、负数、小数、无效日期、不连续日期或非 30 项趋势均视为响应异常，不转换成零值或样例数据。总用户量必须不小于有效用户量，每日累计必须与新增一致，末日累计须等于当前总量。

## 2026-11-03 用户总量与统计周期

安卓原生页面同步 Web 确认后的方案：顶部增加总用户量，保留有效用户与实时在线；趋势增加用户总量并支持近 7 日、近 30 日；新增汇总固定展示三个周期。总用户量卡片不加红色顶栏，不显示每日数据滑块、期末总量及指定累计说明。

周期、指标随当前账号的 Activity 草稿保存，刷新、切换栏目和页面重建可恢复；退出随草稿清除，换号重置。Canvas 采用系统字号，窄屏减少横轴刻度与常驻标签，可点击图表、使用方向键或读屏滚动操作选择每日数据。正文、辅助文字和表格使用深棕色；指标与周期按钮至少 48dp 高。

新增字段依赖已更新的 Backend，部署时先后端再安装新版 Android。默认生产 API 地址保持不变，设备验收使用独立 `.dashboardcheck` 包名和本地后端。
