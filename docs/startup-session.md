# 冷启动与会话恢复

消除独立的“正在连接…”开屏。没有保存有效会话 Cookie 时直接显示可操作登录页，不先请求本人身份；只有设备额度 Cookie 不能作为会话。已在内存中的身份直接恢复对应页面。进程冷启动有保存会话时先显示不含私人数据的食堂页面骨架，后台验证后再进入正常／受限页面。

不缓存角色或密码来绕过校验。会话过期回登录；网络或服务器失败在原页面骨架中显示原因和重试；停用账号仍仅进入申诉会话。重试及迟到响应沿用页面 generation 隔离。

`hasSessionToRestore` 是仓库能力，默认实现保留旧仓库兼容；RemoteRepository 仅检查此服务地址的未过期 `FOODTIME_SESSION`。公开版本检查不再成为登录页展示的前置步骤。

这次改动去掉独立连接等待页，不承诺没有网络等待；已登录账号的恢复仍由服务端确认，不在确认前展示旧用户资料或启用写操作。
