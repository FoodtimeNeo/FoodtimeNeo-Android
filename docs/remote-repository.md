# 真实数据源

`RemoteRepository` 将领域操作映射为 Backend 接口。`restoreSession` 和 `refresh(ContentRequest)` 以及写操作由后台执行；页面读取内存快照，不执行网络。分页读完后以不可变列表替换，重新进入页面会向服务端重查账号和角色。个人历史的所属名称来自服务端关联查询，价格保持可空，不伪造失效父级的数据。

登录后的Cookie仅通过Android Keystore AES/GCM加密保存，不保存密码、角色或个人资料；重启后先向服务端恢复资料，不能以本地值授权。401、退出和改密成功清除Cookie及内存私有数据。CSRF只在内存中保存，登录更换会话后重新获取；写请求不自动重试。

文件上传先得到私有引用，再创建投稿；文件上传成功不代表投稿或审核成功。图片读取使用当前服务同源地址并携带Cookie，绝不把Cookie发送到另一个源。尚未接入界面的阶段不能视为前后端完整联调通过；真实设备验收结果另行记录。
